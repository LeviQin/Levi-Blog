# Levi-Blog 首页 UI 与整体主题改造设计

> 日期：2026-08-06
> 状态：已确认设计方向，待实施

## 1. 目标

将 Levi-Blog 从"个人古风空间"气质改造为"暗色极客风"个人技术博客，提升开发者访客的第一印象与阅读体验，同时保留少量个性元素。

## 2. 设计方向

- **风格**：暗色极客风（GitHub Dark 基底 + Vercel 式克制动效）
- **明暗模式**：默认暗色，保留亮/暗切换开关
- **强调色**：单一青色 `#22d3ee`（亮色模式加深为 `#06b6d4`）
- **范围**：首页 + 全局主题变量 + 顶栏 + 侧边栏 + 文章卡片 + 浮动工具栏
- **古风元素**：以极客为主，保留少量个性（头像、一处签名），移除古风壁纸默认、猫啃字体默认、猫光标

## 4. 字体策略

- 正文：系统无衬线栈（移除猫啃圆体作为默认）
- 标题/标签/日期/数字/logo：等宽字体栈 `ui-monospace, Menlo, Consolas, monospace`
- 保留猫啃字体文件，可用于个别装饰（如签名处），不作为默认

## 5. 首页第一屏重构（Home/Index.vue + TopBanner）

**现状**：100vh 古风女子全屏图 + 打字机标语，看不出是技术博客。

**新方案**：分屏 Hero（Split Screen），高度改为紧凑的 `min-height: 88vh`
- 左侧：大字 `Levi` 标题 + 一句开发者简介 + 入口按钮（查看文章 / 关于我）
- 右侧：终端窗口组件（窗口栏三圆点 + `leviqin:~` 标题 + 几行语法高亮代码/打字机输出）
- 背景：深色纯色 + 细网格线（终端网格感）

**TopBanner 组件调整**：
- 高度从 `100vh` 改为 `min-height: 88vh`
- 打字机保留，但文本改为开发者简介
- 移除古风背景图，改为网格背景

**全局布局背景（layout/Index.vue）**：
- `.banner-bar` 默认 `background-image: url(@/assets/images/banner/gufengnv.jpg)` 改为深色纯色 + 网格/渐变，不再依赖古风图
- 壁纸切换功能（SwitchWallpaper）保留，但"默认壁纸"与兜底 `gufengnvImag` 改为暗色极客底图（如代码网格纹理或深色渐变），远程壁纸选择仍可用

## 7. 明暗切换

- `useTheme.js` 默认值 `light` → `dark`
- 两套变量调好，切换后强调色一致

## 8. 保留项（不动的）

- 路由、数据接口、文章内容、所有功能
- 壁纸切换功能（保留，仅默认不再古风）
- 页面结构（分类/标签/文章列表等）

## 9. 不做的事

- 不引入新依赖（等宽字体用系统栈）
- 不重写文章内容、不改后端
- 不做全站所有页面的深度重做（本阶段聚焦首页 + 全局主题）
